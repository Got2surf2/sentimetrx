## 2026-06-29 — Fix: collection "Members updated — refresh" button silently did nothing

Bug report: clicking the amber refresh badge on a collection card appeared to do nothing. Root cause was NOT server-side — a read-only prod diagnostic confirmed POST /api/collections/[id]/refresh recomputes correctly (bumps the collection dataset's updated_at; members' max(updated,synced) is older → staleness=false server-side). The bug was client state: app/analyze/AnalyzeClient.tsx seeds `const [datasets] = useState(initialDatasets)` and never re-syncs when the prop changes. handleRefreshCollection calls router.refresh(), which re-runs the server component with members_updated:false / fresh row_count — but the seeded useState kept the stale rows, so the badge never cleared (classic derived-state-from-props-not-synced). Fix: `useEffect(() => setDatasets(initialDatasets), [initialDatasets])` — initialDatasets only changes identity on a server re-render (router.refresh / navigation), so local archive/delete optimistic updates between refreshes aren't clobbered. Also clears stale row_count/updated_at after any recompute. tsc clean, 1068 tests, eslint warnings-only.

## 2026-06-29 — Dynamic, data-driven time-framing for trends + charts (lib/trendWindows.ts)

Owner direction: trend windows and chart timeframes must NOT be hard-coded — derive them from the date range of the data in the current view, and let the user optionally pick a reference window. New pure helper deriveTrendWindows(minMs, maxMs, reference): computes an adaptive bucket unit (week ≤90d / month ≤420d / quarter beyond, so any span yields ~6–12 readable buckets) + the chart domain + the recent/prior comparison windows. Reference modes: 'auto' (most-recent third vs prior third — volume-balanced, the default), 'yoy' (recent window vs the SAME window 12 months earlier — controls for seasonality, falls back when <~13mo history), and { recentDays } (explicit trailing window). Too-short spans (<45d) return a chart domain but no comparison windows (trend skipped, not faked). humanDur labels ("last 4 months vs prior 4 months"); bucketKey buckets a timestamp by unit. Shared by BOTH Feature A (Dimensions/theme/quant trend alerts) and Feature B (competitive rating-over-time charts). 7 unit tests, tsc clean.
