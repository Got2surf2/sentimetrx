## 2026-07-06 — Emotion goes universal: the emotion axis decouples from the restaurant gate

WHY: owner caught a scoping gap — disappointment/blame/churn-intent language is vertical-neutral, but the emotion axis only computed inside the restaurant-gated taxonomy classify, so surveys/uploads/PulseIQ datasets could never get it. All §2a discipline holds (expressed-language framing, negation guard, evidence spans, genre zero-suppression, neg-row denominators degrading to null without ratings). Known corner documented in TAXONOMY §2a.0: the foodService upload auto-detect in a non-restaurant org now yields emotion-only — restaurant client orgs should carry restaurant primaryIndustries (org-setup norm). Verified: 3 new rollup tests (1,238 total), tsc clean, lint 3062 held, and a live TEST run on a real survey dataset ("liked LEAST", 11,420 rows): stored rollup contains ONLY the emotion axis — disappointment 5.4% of negative rows / churn 0.8% / blame 0.6%, avg rating 2.1 on flagged rows, evidence spans intact.
